# 07 — الأسئلة المطلوب حسمها

رتّبتها حسب **أثرها على العمل**: الأسئلة 1–4 تغيّر مسار المشروع كله، و5–9 تحسّن الدقة، و10–12
اختيارية. **لا تحتاج للإجابة على الكل** — أجب على ما تعرفه وسأمضي بافتراضات معلنة في الباقي.

---

## القسم الأول — أسئلة تغيّر المسار (الأهم)

### س1 — ماذا تقصد بـ"مقاومة للحرارة" تحديداً؟ ⚠️ الأهم على الإطلاق

هذا السؤال وحده يقسم المشروع إلى مشروعين مختلفين تماماً:

| الاحتمال | يعني | يفرض |
|---|---|---|
| **(أ) مقاومة حريق مبنى** | تعرّض عابر 1–4 ساعات لحماية الأرواح والبنية | كل المسارات مفتوحة، بما فيها غير المحروقة والجيوبوليمرية |
| **(ب) عزل حراري من حرّ الصيف** | خفض حمل التكييف، λ منخفض | التركيز على المسامية والكثافة المنخفضة، والحريق ثانوي |
| **(ج) تعرّض مستمر لحرارة عالية >600 °م** | بطانات أفران، مداخن، منشآت صناعية/نفطية | **المسار السيراميكي المحروق فقط** — كل الروابط المُماهة تسقط |
| **(د) الثلاثة معاً** | منتج متعدد الأغراض | مقطع مركّب متعدد الطبقات حتماً |

**تخميني من صياغة طلبك (مقاومة للحرارة والحريق والأحمال، لجدران، في مناخ العراق):** (أ) + (ب).
إن كان تخميني صحيحاً فأكمل بلا حاجة لجواب. إن كنت تقصد (ج) فأخبرني فوراً — يتغيّر نصف التقرير.

### س2 — ما التطبيق المستهدف بالضبط؟

- [ ] جدران حاملة في مبانٍ سكنية منخفضة الارتفاع (1–3 طوابق)
- [ ] جدران تعبئة/قواطع غير حاملة في هياكل خرسانية
- [ ] كليهما (منتجان بنفس التقنية وكثافتين مختلفتين)
- [ ] تطبيق صناعي/نفطي متخصص
- [ ] أخرى: ________

**لماذا يهم:** مقاومة الانضغاط المطلوبة تقفز من ~5 MPa (تعبئة) إلى ~15–20 MPa (حامل)، وهذا يغيّر
حدود المسامية المسموحة، وبالتالي يغيّر λ الممكن، وبالتالي يغيّر الخلطة كلها.

### س3 — ما هي حدود الاستثمار الرأسمالي المتاح؟

| الخيار | يعني |
|---|---|
| **(أ) تعديل خلطة داخل معمل طابوق قائم** | لا معدات جديدة تقريباً — أرخص وأسرع طريق، وأعلى احتمال نجاح اقتصادي |
| **(ب) خط إنتاج صغير جديد** (خلاط + مكبس + ساحة معالجة) | عشرات آلاف الدولارات |
| **(ج) مصنع متكامل** (قمينة نفقية أو أوتوكلاف) | ملايين الدولارات |
| **(د) بحث مختبري فقط الآن، والتصنيع لاحقاً** | نركّز على العلم لا على اللوجستيات |

**تخميني:** (أ) أو (د). خيار (أ) هو أقصر طريق فعلي إلى "كلفة أقل أو مساوية للموجود".

### س4 — أين بالضبط في الجنوب؟ وهل لديك وصول إلى مواد أولية بعينها؟

الموقع يحدّد كلفة النقل، وكلفة النقل قد تقتل الجدوى وحدها. **البورسلانايت والكاؤولين في الصحراء
الغربية (الأنبار) — والمسافة إلى البصرة تقارب 800–900 كم.** هذا بند حاسم في المرحلة 4.

ما هو المتاح لك فعلياً (أشّر على ما ينطبق):
- [ ] طين/تربة محلية من موقع معيّن (أي محافظة؟)
- [ ] رمل (أي مصدر؟)
- [ ] زجاج مُعاد تدويره / مكسّرات زجاج
- [ ] جبس (خام أو مُكلَّس)
- [ ] كبريت أو مخلفات مصافي
- [ ] مخلفات نخيل / قش أرز / قصب
- [ ] مخلفات بناء وهدم (طابوق مكسور، خرسانة)
- [ ] رماد أو خبث من أي مصدر صناعي
- [ ] إسمنت / جير / سيليكات صوديوم / صودا كاوية (بأي أسعار؟)
- [ ] لا شيء محدّد بعد — أريد التقرير أولاً

## القسم الثاني — أسئلة تحسّن الدقة

### س5 — ما هي الأسعار الحالية في سوقك المحلي؟ (أهم مُدخل للمرحلة 4)

البيانات المنشورة عن الأسعار العراقية شبه معدومة وغير محدّثة. أي رقم تعرفه يساوي أضعاف ما أجده بحثاً:

| المادة | السعر الحالي عندك | الوحدة |
|---|---|---|
| طابوق طيني عادي | | ألف طابوقة / طابوقة |
| ثرمستون (AAC) | | م³ / بلوكة |
| بلوك خرساني | | بلوكة |
| إسمنت | | طن |
| جبس (جص) | | طن |
| رمل / حصى | | م³ |
| غاز طبيعي أو نفط أبيض للحرق | | م³ / لتر |
| كهرباء صناعية | | كيلوواط.ساعة |
| أجرة عامل يومية | | يوم |

### س6 — هل هناك معيار أداء ملزم يجب تحقيقه؟

مثلاً: مواصفة عراقية بعينها، اشتراط جهة حكومية، متطلب مشروع أو مناقصة، أو تصنيف حريق محدّد
(ساعة؟ ساعتان؟ أربع؟). إن وُجد رقم ملزم فسأصمّم عليه مباشرة بدل التصميم على نطاق.

### س7 — هل لديك وصول إلى مختبر؟

- [ ] مختبر جامعي (أي جامعة؟ وما الأجهزة المتاحة؟)
- [ ] مختبر إنشائي تجاري
- [ ] لا — أحتاج قائمة بالفحوص وأين تُجرى في العراق
- [ ] لا، والعمل نظري بالكامل في الوقت الحالي

يحدّد هذا شكل بروتوكول التجارب في المرحلة 5: هل أكتب بروتوكولاً كاملاً بأجهزة متقدمة (XRD، SEM،
TGA، Hot Disk) أم بروتوكولاً بأدوات بسيطة (مكبس انضغاط، فرن، ميزان، حوض غمر)؟

### س8 — ما مستوى العمق المطلوب في التقرير النهائي؟

- [ ] تقرير تنفيذي مركّز (30–50 صفحة) لاتخاذ قرار
- [ ] تقرير تقني مفصّل (100–200 صفحة) بكل الجداول والمراجع
- [ ] مرجع بحثي شامل بلا سقف — كل ما يمكن جمعه
- [ ] تقرير + عرض تقديمي/صفحة تفاعلية قابلة للمشاركة

### س9 — لغة المصطلحات التقنية

- [ ] عربي مع المصطلح الإنجليزي بين قوسين (المعتمد حالياً)
- [ ] عربي خالص
- [ ] عربي + جداول بالإنجليزية

## القسم الثالث — أسئلة اختيارية

### س10 — هل الاستدامة/البيئة هدف معلن أم أثر جانبي؟
يؤثر على وزن معيار "خفض الانبعاثات" في مصفوفة القرار النهائية، وعلى إمكانية استهداف تمويل أخضر.

### س11 — هل تريد تغطية الجانب التجاري؟
(دراسة سوق، تحليل منافسين، نموذج ربحية، خطة تسويق) — أم التقرير تقني بحت؟

### س12 — هل هناك أنواع أو تقنيات بعينها تريد التركيز عليها أو استبعادها مسبقاً؟
مثلاً: "لا أريد أي شيء يحتاج حرقاً"، أو "ركّز على الجيوبوليمر"، أو "أريد شيئاً يُنتَج يدوياً".

## ماذا سأفعل إن لم تُجب

سأمضي في **المرحلة 2** بالافتراضات التالية معلنةً بوضوح، وسيبقى تعديلها ممكناً لاحقاً:

1. المقصود بـ"مقاومة الحرارة" = **مقاومة حريق مبنى (1–4 ساعات) + عزل حراري صيفي** — لا تعرّض
   صناعي مستمر فوق 600 °م.
2. التطبيق = **جدران حاملة سكنية منخفضة الارتفاع + قواطع** (منتجان بكثافتين).
3. الاستثمار = **تعديل خلطة داخل معمل قائم** كأولوية، مع تقييم خط صغير جديد كبديل.
4. الموقع = **البصرة ومحيطها**، مع حساب كلفة نقل مواد الصحراء الغربية كبند صريح.
5. مستوى التقرير = **تقني مفصّل**، عربي مع المصطلحات الإنجليزية بين قوسين.
