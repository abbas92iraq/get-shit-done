## الملخص التنفيذي في عشرة أسطر

1. النظام **منصة واحدة متعددة المستأجرين** تخدم أربعة خطوط أعمال: مقاولات إنشائية، تطوير عقاري، صيانة وتشغيل مرافق، خدمات هندسية استشارية.
2. المعمارية **Modular Monolith** مقسّم إلى نطاقات (Bounded Contexts) قابلة للفصل لاحقاً إلى خدمات مصغّرة عند الحاجة فقط.
3. **27 نطاقاً وظيفياً** تغطي كل أقسام الإدارة بلا استثناء، من التقدير حتى التسليم النهائي والضمان.
4. العمود الفقري للنظام هو **دفتر الكلفة (Cost Ledger)**: كل حركة في أي قسم تُرحّل إلى كود كلفة ومركز مسؤولية وقيد محاسبي.
5. الربط بين الأقسام يتم عبر **أحداث النطاق (Domain Events)** بنمط Transactional Outbox — لا استدعاءات مباشرة متشابكة.
6. المزامنة الميدانية **Offline-First**: تطبيق جوال يعمل بلا إنترنت في المواقع النائية ويزامن بذكاء عند العودة.
7. **الأتمتة الكاملة** عبر محرك سير عمل مركزي + محرك قواعد + طبقة ذكاء اصطناعي للتنبؤ والاستخراج والكشف.
8. **الأمان**: عزل بيانات على مستوى الصف (RLS)، صلاحيات ABAC، تشفير الحقول الحساسة، سجل تدقيق غير قابل للتعديل.
9. **الأداء**: أهداف P95 < 300ms للقراءات، فصل أحمال التقارير عن العمليات، تقسيم الجداول الزمنية.
10. التنفيذ على **7 مراحل خلال 18–24 شهراً** مع إطلاق أول قيمة تشغيلية في الشهر الرابع.

## القرارات المعمارية المفتوحة للنقاش

هذه نقاط تحتاج قرارك قبل بدء التنفيذ — مفصّلة في نهاية كل وثيقة:

- **نموذج النشر**: سحابي مشترك (SaaS) أم نسخة خاصة لكل شركة (On-Prem/Private Cloud)؟
- **المنطقة والامتثال الضريبي**: العراق / السعودية (زاتكا) / الإمارات / مصر — يحدد وحدة الفوترة الإلكترونية والضرائب.
- **لغة الواجهة الأساسية**: عربي RTL أولاً مع إنجليزي كامل، أم ثنائي متكافئ؟
- **عمق تكامل BIM**: عرض IFC فقط، أم ربط كميات 5D بالتقدير؟
- **الجدولة**: محرك CPM داخلي، أم تكامل مع Primavera P6 / MS Project؟
- **الرواتب**: محرك رواتب داخلي، أم تكامل مع نظام قائم؟
