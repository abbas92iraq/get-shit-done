# 14 — تطبيق العقود · المواصفة التفصيلية

> التطبيق الأول بعد القلب. الأسابيع ٩–١٤.
> **بلا كود** — هذه مواصفة شاشات وحقول وقواعد.
> المستودع عام: لا أرقام ولا أسماء من مستندات الشركة.

## 0. حدود التطبيق

**يملك:** العقد · الكشف المسعّر (جدول الكميات) · أوامر الغيار · التبويب الموازني · المدد والتواريخ · قواعد الغرامات والاحتياط · قوالب طباعة الثلاثة.

**لا يملك (ويقرؤه من القلب):** المشروع · الشركاء · العملات · أكواد الكلفة · الصلاحيات · سير العمل · الملفات.

**لا يملك (ويسأل عنه بواجهة معلنة):** الإنجاز التراكمي والمصروف ← من تطبيق الدفعات.

**مخطط قاعدة البيانات:** `contracts.*` حصراً.

## 2. حالات العقد

```
مسودة ──▶ قيد الاعتماد ──▶ معتمد ──▶ موقّع ──▶ مباشَر ──▶ قيد التنفيذ
                                                              │
        ┌─────────────────────────────────────────────────────┤
        ▼                        ▼                            ▼
     متوقف ──▶ (استئناف)   منجَز فعلياً ──▶ مدة الصيانة ──▶ مغلق
        │
        └──▶ مسحوب العمل  (حالة نهائية منفصلة)
```

| الحالة | ما يُسمح | ما يُمنع |
|--------|----------|----------|
| **مسودة** | تحرير كل شيء | الطباعة الرسمية · إنشاء دفعات |
| **قيد الاعتماد** | قراءة · اعتماد · رفض | التحرير |
| **معتمد** | تسجيل التوقيع | تحرير الكشف |
| **موقّع** | تسجيل تسليم الموقع والمباشرة | ✋ **تجميد الكشف** — لا تعديل إلا بأمر غيار |
| **مباشَر / قيد التنفيذ** | أوامر غيار · ذرعات · دفعات · تمديدات | تعديل مبالغ العقد مباشرة |
| **متوقف** | تسجيل الاستئناف | ذرعات جديدة · احتساب أيام التأخير |
| **منجَز فعلياً** | لجنة الاستلام الأولي · الدفعة الختامية | أوامر غيار جديدة |
| **مدة الصيانة** | تحرير الاحتياط · الاستلام النهائي | أعمال جديدة |
| **مغلق / مسحوب** | قراءة فقط | كل شيء |

**التوقيع يُجمّد الكشف** (`boq_frozen_at`) — وهذه أهم بوابة في التطبيق كله:
بعدها لا يتغيّر بند ولا سعر ولا رقم صفحة إلا عبر أمر غيار معتمد.

## 3. الشاشات

### ش١ · قائمة العقود
**الأعمدة:** رقم العقد · المشروع · رب العمل · المبلغ الأصلي · المبلغ المعدّل · المنجز٪ · المدة المتبقية · حالة الغرامة · الحالة

**المرشّحات:** الحالة · السنة · برنامج التمويل · رب العمل · المشروع · حالة الخطر

**شرائح الحالة الملوّنة:** مسودة (رمادي) · موقّع (أزرق) · قيد التنفيذ (أخضر) · متوقف (كهرماني) · متأخر (أحمر) · مغلق (باهت)

**مؤشر خطر الغرامة** في كل صف — شريط أفقي يعرض نسبة استهلاك سقف الغرامة، يتحول أحمر عند بلوغ عتبة الإجراءات.

**إجراءات سريعة:** عقد جديد · تصدير · طباعة كشف الحالة

---

### ش٢ · معالج عقد جديد — أربع خطوات

**خطوة ١ — الهوية والإحالة**
المشروع (من القلب) · رب العمل · الدائرة المستفيدة · دائرة المهندس المقيم · رقم وتاريخ كتاب الإحالة · رقم التعاقد المباشر · رقم وتاريخ العقد · مرفق كتاب الإحالة.

**خطوة ٢ — التبويب الموازني**
سبعة حقول رقمية في صف واحد + برنامج التمويل وسنته.
معاينة فورية للتبويب المجمّع. حفظ كتبويب مفضّل لإعادة الاستخدام.

**خطوة ٣ — الشروط المالية والزمنية**
اختيار **قالب عقد** يملأ كل ما يلي دفعة واحدة، ثم يُعدَّل:

| الحقل | ملاحظة |
|-------|--------|
| مبلغ العقد | يُقارن لاحقاً بمجموع الكشف — يجب التطابق |
| نسبة مبلغ الاحتياط | تُخصم من كل دفعة |
| نسبة الاستقطاع الضريبي | تُخصم عند الصرف |
| سلفة مقدمة | ☐ معطّلة افتراضياً — تُفعَّل بمعرفة صريحة |
| مدة الإنجاز · نفاذ العقد · تسليم الموقع | بالأيام |
| نسبة الغرامة اليومية · سقف الغرامات · عتبة الإجراءات · التحميلات الإدارية | |
| مهلة برنامج تقدم العمل · غرامته اليومية | |
| مدة الصيانة | بالأشهر |
| ☐ يُسمح بالتعاقد الثانوي · ☐ يُسمح بالتعويض عن التمديد | معطّلتان افتراضياً |

**خطوة ٤ — الكشف المسعّر**
استيراد من Excel · إدخال يدوي · نسخ من عقد سابق. تنتهي بشاشة ش٤.

---

### ش٣ · بطاقة العقد

#### لوحة العقد (أعلى الشاشة — ستة مقاييس)

| المقياس | الاشتقاق |
|---------|----------|
| **المبلغ الأصلي** | من العقد |
| **المبلغ المعدّل** | الأصلي + صافي أوامر الغيار المعتمدة · مع شارة عدد الأوامر |
| **المنجز التراكمي** | ← `payments.getCertifiedToDate(contractId)` · ونسبته |
| **المتبقي** | المعدّل − المنجز |
| **المدة** | الأصلية + التمديدات · الأيام المنقضية والمتبقية · شريط تقدم |
| **الغرامة** | اليومية المحسوبة · المتراكمة · نسبة استهلاك السقف |

**بطاقة الغرامة** هي أهم عنصر بصري في الشاشة:
```
الغرامة اليومية = (المبلغ المعدّل ÷ المدة المعدّلة) × نسبة الغرامة اليومية
المتراكمة       = اليومية × أيام التأخير (بعد استبعاد أيام التوقف المعتمدة)
السقف           = المبلغ المعدّل × نسبة السقف
```
- الغرامة اليومية **تتغيّر تلقائياً مع كل أمر غيار** لأنها دالة في المبلغ والمدة معاً.
- عند بلوغ عتبة الإجراءات ← **تنبيه أحمر دائم** في اللوحة وفي قائمة العقود وفي بريد الإدارة.

#### التبويبات السبعة
1. **البيانات الأساسية** — الهوية والإحالة والتبويب الموازني
2. **الشروط** — كل الشروط المالية والزمنية، للقراءة مع سجل تغييرات
3. **الكشف المسعّر** ← ش٤
4. **أوامر الغيار** ← ش٦
5. **المدد والتواريخ** ← ش٨
6. **المستندات** — العقد · الإحالة · المباشرة · التأمين · تأييد الضمان الاجتماعي · شهادات الاستلام. لكل وثيقة تاريخ صلاحية وتنبيه تجديد
7. **الدفعات** — عرض للقراءة فقط من تطبيق الدفعات

### ش٤ · الكشف المسعّر

**شبكة بمستويين:** أقسام قابلة للطي، وبنود داخلها.

```
▼  ١ ــ الأعمال المدنية / القاعدة الكونكريتية        المجموع: ●●●●●●
   ┌────┬───────┬────────────────────────┬───────┬────────┬──────────┬──────────┐
   │ ت  │ صفحة  │ التفاصيل               │الوحدة │ الكمية │سعر المفرد│  المبلغ  │
   ├────┼───────┼────────────────────────┼───────┼────────┼──────────┼──────────┤
   │١-١ │   ١   │ تجهيز مواد والقيام…    │ عدد   │      ١ │  ●●●●●●  │ ●●●●●●   │
   │    │       │ [عرض النص كاملاً ▾]    │       │        │          │          │
   └────┴───────┴────────────────────────┴───────┴────────┴──────────┴──────────┘
▶  ٢ ــ الأعمال الكهربائية                          المجموع: ●●●●●●
────────────────────────────────────────────────────────────────────────────────
مجموع الكشف: ●●●●●●        مبلغ العقد: ●●●●●●        ✅ مطابق
```

**قواعد العرض:**
- عمود **الصفحة** ظاهر دائماً — لأنه هوية البند في كل مستند خارجي.
- **الوصف يُعرض في ثلاثة أسطر** مع زر توسيع. النص الكامل محفوظ حرفياً ويُطبع كما هو.
- **المبلغ محسوب** — لا يُحرَّر.
- مجموع كل قسم في رأس القسم المطوي.
- شريط سفلي ثابت: مجموع الكشف · مبلغ العقد · **مؤشر المطابقة**.

**بوابة إلزامية:**
> **لا يُعتمد العقد ما لم يساوِ مجموع الكشف مبلغ العقد بالضبط.**
> الفارق يُعرض بلونه وإشارته، مع زر «اذهب إلى القسم المسبِّب».

**الاستيراد من Excel:** رفع → مطابقة الأعمدة → معاينة → التحقق → تثبيت.
يكتشف الأقسام من الصفوف التي بلا كمية، ويستنتج رقم الصفحة من عمود مخصص أو من فواصل الصفحات.

**بعد التوقيع:** الشبكة كلها للقراءة فقط، وشريط علوي: «الكشف مجمّد بتاريخ … — التعديل بأمر غيار» مع زر **إنشاء أمر غيار**.

### ش٥ · محرر البند
حوار جانبي: القسم · رقم البند · رقم الصفحة · **الوصف الفني** (محرر نص كبير بعدّاد أحرف) · الوحدة · الكمية · سعر المفرد · المبلغ (محسوب) · كود الكلفة (اختياري).

**تنبيه:** لصق الوصف من Word يجب أن يحافظ على فواصل الأسطر ويزيل التنسيق — الوصف مرجع تعاقدي عند الخلاف.

### ش٦ · قائمة أوامر الغيار
**الأعمدة:** رقم الأمر · التاريخ · رقم الأمر الإداري · السبب · الزيادة · النقصان · **الصافي** · ± الأيام · الحالة

**شريط تراكمي أعلى القائمة:**
```
العقد الأصلي  ●●●●●●   +الزيادات ●●●●●●   −النقصانات ●●●●●●   = المعدّل ●●●●●●
نسبة التغيير من الأصلي: ●●٪   [شريط بعتبة تحذير]
```

**تنبيه الحد النظامي:** حين تقترب نسبة التغيير التراكمي من الحد المسموح في تعليمات تنفيذ العقود الحكومية ← تحذير قبل الاعتماد لا بعده.

### ش٧ · محرر أمر الغيار — الشاشة الأهم في التطبيق

الشبكة تُطابق المستند الرسمي عموداً بعمود:

```
┌───┬─────────┬────────────┬──────┬────────────────────────┬────────────────────────┬─────────┬─────────┐
│ ت │  مرجع   │  التفاصيل  │الوحدة│   حسب الكشف الفني      │   حسب أمر الغيار       │ الزيادة │ النقصان │
│   │فقرة/صفحة│            │      │ الكمية · المفرد · المبلغ│ الكمية · المفرد · المبلغ│         │         │
├───┼─────────┼────────────┼──────┼────────────────────────┼────────────────────────┼─────────┼─────────┤
│ ١ │ ١-٢ / ١ │ الدفن…     │ م³   │  ●●● ·  ●●●  ·  ●●●    │  ●●● ·  ●●●  ·  ●●●    │  ●●●    │    —    │
│ ٢ │ ١-٨ / ١ │ تجهيز ومد… │ م.ط  │  ●●● ·  ●●●  ·  ●●●    │  ──── · ──── · ────    │    —    │  ●●●    │
│ ٣ │  جديد   │ فقرة جديدة │ عدد  │  ──── · ──── · ────    │  ●●● ·  ●●●  ·  ●●●    │  ●●●    │    —    │
└───┴─────────┴────────────┴──────┴────────────────────────┴────────────────────────┴─────────┴─────────┘
مجموع الزيادة ●●●●   مجموع النقصان ●●●●   الصافي ●●●●   المبلغ المعدّل الجديد ●●●●
```

**ثلاثة أزرار إضافة:**
| الزر | السلوك |
|------|--------|
| **تعديل بند قائم** | بحث بالفقرة/الصفحة أو بالوصف ← يملأ جانب «الكشف الفني» تلقائياً ← يُحرَّر جانب «أمر الغيار» فقط |
| **حذف بند** | يملأ جانب الكشف ويضع `----` في جانب الأمر ويحوّل المبلغ كاملاً إلى النقصان |
| **بند جديد** | جانب الكشف `----` · يُدخَل الوصف والوحدة والكمية والسعر |

**قواعد:**
- **سعر المفرد مقفل افتراضياً** — لأن العقد يمنع المطالبة بزيادة الأسعار. فتحه يتطلب صلاحية خاصة وسبباً مكتوباً يظهر في الطباعة.
- الزيادة والنقصان **محسوبان** ولا يُدخلان.
- لا يُضاف بند مرجعه مستخدَم في أمر غيار **معتمد** سابق دون تنبيه صريح.
- تغيير المدة `± أيام` حقل مستقل يؤثر على المدة المعدّلة **وعلى صيغة الغرامة**.

**بعد الاعتماد:** الأمر يُقفل نهائياً. التعديل بأمر غيار جديد فقط. والمبلغ المعدّل للعقد يُعاد حسابه، **وحدث `VariationApproved` يُنشر**.

### ش٨ · المدد والتواريخ

**خط زمني أفقي** يعرض: الإحالة → العقد → التوقيع → النفاذ → تسليم الموقع → المباشرة → الإنجاز المخطط (الأصلي) → التمديدات → الإنجاز المعدّل → الإنجاز الفعلي → الاستلام الأولي → مدة الصيانة → الاستلام النهائي.

**مع «اليوم» كخط عمودي** — فيُرى التأخير أو التقدم بالنظر لا بالحساب.

**جدول أحداث المدة** — كل حدث بتاريخه ومستنده وأثره بالأيام. **سجل لا يُعدَّل**، التصحيح بحدث معاكس.

**آلة حاسبة الغرامة** — لوحة جانبية تعرض المعادلة بأرقامها الحالية خطوة بخطوة، بحيث يستطيع مدير المشروع أن يشرحها للجهة المستفيدة من الشاشة مباشرة.

**عدّاد برنامج تقدم العمل** — يظهر فور تسجيل المباشرة: الأيام المتبقية لتقديم البرنامج، وتحت الصفر يبدأ عدّاد الغرامة اليومية المقطوعة.

### ش٩ · الطباعة

ثلاثة قوالب **تطابق الأصل حرفياً**:

| القالب | المتطلب الحرج |
|--------|----------------|
| **العقد** | ترقيم الصفحات `٣-١` · جدول تبويب المشروع · بنود الشروط الخاصة مرقّمة · كتلة توقيع الطرفين |
| **الكشف المسعّر** | **الحفاظ على أرقام الصفحات الأصلية** · عناوين الأقسام · مجموع كل قسم · تكرار رأس الجدول في كل صفحة |
| **أمر الغيار** | ترويسة تتكرر في كل صفحة (المحافظة · المشروع · الشركة · رقم الأمر · برنامج التمويل) · **كتلة توقيعات اللجنة في أسفل كل صفحة** · `Page n of N` |

**القاعدة الحاكمة:** رقم الصفحة المطبوع = `source_page_no` المخزّن. إن اختلفا انكسرت مرجعية كل مستند سابق. يُختبر آلياً.

## 4. قواعد المنع (Gates)

| # | القاعدة | متى |
|---|---------|-----|
| ١ | مجموع الكشف = مبلغ العقد بالضبط | قبل الاعتماد |
| ٢ | لا اعتماد بلا تبويب موازني مكتمل | قبل الاعتماد |
| ٣ | لا تعديل على الكشف بعد التوقيع | دائماً |
| ٤ | لا أمر غيار على عقد غير مباشَر | إنشاء أمر غيار |
| ٥ | لا تعديل أمر غيار معتمد | دائماً |
| ٦ | لا تغيير سعر مفرد بلا صلاحية خاصة وسبب مكتوب | محرر أمر الغيار |
| ٧ | لا مباشرة بلا تاريخ تسليم موقع مسجّل | تسجيل المباشرة |
| ٨ | لا إغلاق عقد وله أمر غيار مسودة أو دفعة غير مصروفة | الإغلاق |
| ٩ | تحذير عند اقتراب نسبة التغيير التراكمي من الحد النظامي | قبل اعتماد أمر الغيار |
| ١٠ | تنبيه أحمر عند بلوغ الغرامة عتبة إجراءات السحب | يومياً |
| ١١ | لا حذف عقد — إبطال فقط مع سبب | دائماً |

## 7. الواجهة المعلنة `apps/contracts/public.ts`

ما تراه التطبيقات الأخرى — **ولا شيء غيره**:

```
getContract(contractId)              → الهوية والمبالغ والمدد والحالة
getBoqItem(contractId, page, itemNo) → بند واحد بوصفه ووحدته وكميته وسعره
listBoqItems(contractId)             → كل البنود مع الكميات المعتمدة حالياً
getRevisedAmount(contractId)         → المبلغ بعد أوامر الغيار المعتمدة
getFinancialTerms(contractId)        → نسب الاحتياط والاستقطاع والغرامة والسقف
getDurationState(contractId)         → المدة المعدّلة · الأيام المنقضية والمتبقية · حالة التأخير
calculateLd(contractId, asOfDate)    → الغرامة اليومية والمتراكمة ونسبة استهلاك السقف
getBudgetClassification(contractId)  → التبويب الموازني السباعي
```

`payments` يستخدم الأربعة الأولى لبناء الذرعة والدفعة.
`treasury` يستخدم `getFinancialTerms` و`getDurationState` لتوقع التدفق.

## 8. معيار الإنجاز

> يُدخَل عقد حكومي حقيقي كاملاً بكشفه وأوامر غياره،
> وتُطبَع الثلاثة بشكل **يقبله المهندس المقيم دون تعديل يدوي**،
> وتظهر الغرامة اليومية والمتراكمة صحيحة ومتطابقة مع الحساب اليدوي.

عند تحقق هذا يبدأ **تطبيق الدفعات** — وهو المستهلك الأول لهذه الواجهة.
